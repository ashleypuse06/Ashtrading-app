Configuration requise

Cette app doit être connectée à votre propre projet Supabase avant de fonctionner.

Ouvrez ce fichier dans un éditeur de texte et remplacez, tout en haut du <script> :

SUPABASE_URL et SUPABASE_ANON_KEY par les valeurs de votre projet (Project Settings → API dans Supabase).

Puis enregistrez le fichier et rechargez la page.
